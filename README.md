# Learning Python 🐍

Python fundamentals from an experienced C# developer's perspective.
Each file is runnable: `python 01-fundamentals/00_introduction.py`

## Progress

| Status | File | Concepts |
| -------- | ------ | ---------- |
| ✅ | `00_introduction.py` | Why Python, Python 2 vs Python 3, checking your interpreter |
| ✅ | `01_variables_types.py` | Dynamic typing, str/int/float/bool/None, `type()` |
| 📋 | `02_strings.py` | f-strings, `.strip()/.split()/.join()`, slicing `[:5]`, `[::-1]` |
| 📋 | `03_lists.py` | Lists, indexing, slicing, `.append()/.sort()`, list comprehensions |
| 📋 | `04_dicts.py` | Dict CRUD, `.get()`, `.items()`, `in` operator (vs `Dictionary`) |
| 📋 | `05_control_flow.py` | `if/elif/else`, `for/in`, `range()`, `enumerate`, `while` |
| 📋 | `06_functions.py` | `def`, default args, multiple returns, `*args`/`**kwargs`, lambdas |
| 📋 | `07_operators.py` | Arithmetic (`**`, `//`), comparison, chained, logical (`and`/`or`/`not`), identity (`is`), membership (`in`) |

## Running the examples

```bash
# From the repo root
python 01-fundamentals/00_introduction.py

# Check which Python you're on (Windows also has the py launcher)
python --version
py -3 --version
```
